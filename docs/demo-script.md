# ClientFlow 60–90 second demo

Target duration: about 80 seconds. Use a desktop viewport and the public demo account. Because the account is shared, give the new lead a unique suffix such as the current time and archive it after recording.

## Before recording

1. Open the [live application](https://clientflow-web-abrarui12-kocw.onrender.com) once so the free API can wake up.
2. Sign out, close unrelated tabs, and hide bookmarks or personal browser information.
3. Prepare a lead name such as `Northstar Studio 1425` and one quote line: `Discovery workshop`, quantity `2`, unit price `7500`.
4. Keep the browser at 1440×900 and zoom at 100%.

## Recording script

| Time | Action | Narration |
| --- | --- | --- |
| 0–7s | Log in with the visible demo credentials. | “ClientFlow is a focused CRM for turning freelance leads into accurate quotes and next actions.” |
| 7–15s | Pause on the dashboard; point to pipeline, open quotation value, and reminders. | “The dashboard summarizes one owner's live pipeline, quotation value, and timezone-aware follow-ups.” |
| 15–25s | Open Leads, choose New lead, enter the prepared name and required contact fields, then save. | “I can capture a prospect without leaving the workflow; every record is isolated to the authenticated owner.” |
| 25–40s | Choose Create quotation, add the prepared line, then set 10% discount and 5% tax. | “The preview updates immediately, but the browser never supplies final totals—the API recalculates every amount with fixed-precision decimals.” |
| 40–50s | Save, then mark the quotation Sent. | “Quotation states are enforced: drafts can be edited, sent quotes can be accepted or rejected, and terminal states are locked.” |
| 50–58s | Download and briefly show the PDF. | “The customer-ready PDF comes from the owned server record and its authoritative totals.” |
| 58–70s | Return to the lead, add a follow-up due today, and save. | “Follow-ups require an explicit time offset and are grouped using the user's configured timezone.” |
| 70–80s | Return to Dashboard and show the refreshed metrics/reminder. | “Related views invalidate immediately, so the new lead, quote, and next action are reflected without a manual refresh.” |

## Optional close

End on the dashboard and say: “The repository includes PostgreSQL migrations, 134 backend tests, responsive Playwright coverage, production smoke tests, and the full architecture handoff.”

After recording, archive the uniquely named lead so it no longer appears in normal lists or dashboard metrics. Do not use the production-only-disabled reset command.
